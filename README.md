## Selected Projects

### SongCi LLM · Domain Model for Classical Chinese Ci Poetry

Built a domain-specific model based on **Qwen2.5-7B-Instruct**, covering corpus cleaning, rhythmic knowledge-base construction, knowledge distillation, multi-stage fine-tuning, and evaluation.

- Organized 30 tune patterns, 192 rhythmic variants, and about 30,000 Chinese prosody rules
- Constructed 500 SFT samples and 810 CoT samples
- Designed the `SongCiReward` evaluation method and completed an SFT → CoT → GRPO alignment pipeline
- Improved the comprehensive prosody score from 37.43 to 80.86

`Qwen2.5` `SFT` `CoT` `GRPO` `Reward Modeling` `Digital Humanities`

### [Job Information Retrieval System](https://github.com/XDforever-lab/job-info-retrieval-system)

A vertical search and text-analysis system built from Chinese recruitment data.

- Processed 93,602 raw records and constructed a 5,000-document retrieval corpus
- Implemented an inverted index and TF-IDF vector-space ranking from scratch
- Compared seven Chinese word-segmentation methods
- Added multi-field retrieval, query parsing, text classification, similar-job recommendation, REST APIs, and visual analytics

`Python` `TF-IDF` `Information Retrieval` `Flask` `ECharts`

### [EShop Intelligence Dashboard](https://github.com/XDforever-lab/dashboard)

An e-commerce analytics and decision-support platform for reproducible business analysis.

- Unified the definitions of GMV, average order value, refund rates, and session-level funnels
- Built nine modules covering RFM, repurchase propensity, association rules, forecasting, ROAS, fulfillment, and after-sales analysis
- Added rolling backtests with MAE, MAPE, and RMSE
- Delivered an interactive dashboard with FastAPI, SQLite, and ECharts

`Python` `SQL` `SQLite` `FastAPI` `ECharts` `Docker`
