## 代表项目

### 宋词大模型 · 古典词领域模型

基于 **Qwen2.5-7B-Instruct** 构建宋词领域模型，完成语料清洗、格律知识库建设、知识蒸馏、多阶段微调与模型评测。

- 整理 30 个词牌、192 种格律变体和约 3 万条诗词格律规则
- 构建 500 条 SFT 样本和 810 条 CoT 样本
- 设计 `SongCiReward` 评测方法，完成 SFT → CoT → GRPO 对齐流程
- 将格律综合得分从 37.43 提升至 80.86

`Qwen2.5` `SFT` `CoT` `GRPO` `Reward Modeling` `数字人文`

### [招聘信息检索系统](https://github.com/XDforever-lab/job-info-retrieval-system)

基于中文招聘数据开发的垂直搜索与文本分析系统。

- 处理 93,602 条原始记录，构建包含 5,000 篇文档的检索语料库
- 从零实现倒排索引和 TF-IDF 向量空间排序
- 比较 7 种中文分词方法
- 实现多字段检索、查询解析、文本分类、相似职位推荐、REST API 和可视化分析

`Python` `TF-IDF` `信息检索` `Flask` `ECharts`

### [EShop 智能分析看板](https://github.com/XDforever-lab/dashboard)

面向电商业务的可复现分析与决策支持平台。

- 统一 GMV、客单价、退款率和会话级漏斗等指标口径
- 建设 9 个模块，覆盖 RFM、复购倾向、关联规则、预测、ROAS、履约与售后分析
- 通过 MAE、MAPE 和 RMSE 实现滚动回测
- 基于 FastAPI、SQLite 和 ECharts 交付交互式看板

`Python` `SQL` `SQLite` `FastAPI` `ECharts` `Docker`
